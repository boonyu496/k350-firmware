# K350 跟随小车固件

本仓库**只存放编译好的固件二进制**（`.bin`）和版本清单，**不含源代码**。

源代码在私有仓库维护。小车通过 HTTPS 下载固件完成远程 OTA 升级，不需要 GitHub 账号或密钥。主地址是本仓库的 `raw.githubusercontent.com` 直链；因为它在国内经常连不上，`latest.json` 还给出 jsDelivr 镜像（`mirrors`），固件 v1.4.5 起会自动在这些地址之间切换。无论从哪个地址下载，都必须通过 SHA256 校验才会写入。

v1.4.7 起每个固件都有**发布签名**（`sig`，ECDSA P-256，签的是 `K350FW|<ver>|<sha256>|<size>` 这一行，即版本号、SHA256、字节数一起签；也单独放在 `firmware/<文件名>.sig`）。版本号在签名里，所以旧版本的签名不能拿来冒充新版本。小车只装签名正确的固件（小车自己下载、手机转发、远程升级都一样）；签名私钥只在发布者电脑上，不在任何仓库里。

## 最新版本

请查看 [`latest.json`](./latest.json)，或打开 [`firmware/`](./firmware/) 目录中对应版本的 `.bin` 文件。

`latest.json` 字段：

- `ver`：版本号
- `url`：固件直链
- `sha256`：SHA256 校验值（小写十六进制）
- `sig`：发布签名（128 位十六进制 r‖s，签的是 `K350FW|<ver>|<sha256>|<size>`；v1.4.7 起才有，小车 v1.4.7 起要求有）
- `size`：字节数
- `date`：发布日期
- `mirrors`：备用下载地址（jsDelivr 镜像，固定到放入该 bin 的提交；v1.4.5 起才有）
- `notes`：更新说明（可选，小车网页「发现新版本」时显示）

历史版本见 [`versions.json`](./versions.json)。

## 使用方法

- 用户：手机连小车 WiFi，打开 http://192.168.4.1 ，点「检查更新」→「立即升级」。
- 开发者：在 `remote_console.html` 中点击「检查最新版本」，确认后即可远程升级。
